使用与交接说明

这份文档写给两类人：现在想开始学习的你，以及未来接手维护、扩充这个网站的任何人。读完它，不需要原始开发者也能继续把网站运营下去。

贝尔实验室 · 计算机知识学习站（Bearlabs）· 11 门课程 / 116 讲 / 双讲解 / 三级习题 / 交互动画 · 零第三方依赖

一、五分钟上手

1安装 Node.js 18+（仅启动本地服务需要；纯浏览也可用任意静态服务器）。

2Windows 双击 start.bat；macOS / Linux 执行 node server/server.js（或 npm start）。

3浏览器打开控制台打印的地址（默认 http://127.0.0.1:8642/）。控制台还会打印管理员密钥（存于 server/data/admin-key.txt），用于 #/admin 学习记录台账。

没有 Node 也可以把整个文件夹丢给任意静态托管（Netlify / Vercel / GitHub Pages，配置已备好在 deploy/）。差别只有一点：静态托管下「账号同步、管理员台账」不可用，其余功能完全一致，学习数据保存在浏览器本地。

二、这个网站有什么

11 门课程 · 116 讲

组成原理、网络、操作系统、数据结构与算法、面向对象编程（本科核心）＋数据库、编译原理、离散数学与计算理论、AI·机器学习入门（研究生入门导读）＋人工智能的数学基础（大学基础）＋大厂面试实战题库（求职冲刺）。每门课标注层次、先修与学习路径。

双讲解

每讲都有「专业版」（术语、定义、推导）与「宝宝巴士版」（生活类比、零基础可读），一键切换且保留阅读位置；两版讲同一批知识点，结论一致。

三级习题 + 完整解答

每讲 10 题（简单 4 / 中等 4 / 困难 2），五要素解答：思路 → 分步 → 结果 → 常见错误 → 零基础说明；编程题代码可运行、输出经过实测。

16 个交互动画

进程调度、TCP、内存与指针、浮点数、缓存、流水线、排序 / 查找 / 图遍历、面向对象建模、编译流程、神经网络等；全部支持重置 / 单步 / 播放 / 速度 / 参数，每步配旁白。

v1.2 更新（2026-09-22）：新增「人工智能的数学基础」（8 讲）与「大厂面试实战题库」（8 讲 80 题：来源标注 + 备考自查清单）两门课程，并新增「大厂冲刺线」学习路径；离散数学课程零改动。完整变更清单见 README 的「更新记录」一节。

三、推荐的学习流程

  1. 首页 → 学习路径：选一条线（零基础选「轻松起步线」；本科主线按 编程 → 算法 → 组成 → OS → 网络 → 数据库；进阶读「深造线」）。
  2. 进入课程 → 从第一讲开始。章节页顶部可随时切换专业版 / 宝宝巴士版；建议先读通俗版建立直觉，再读专业版巩固。
  3. 章节内遇到 动手实验 标记的交互演示，按旁白亲手操作一遍（重置 / 上一步 / 下一步都能点）。
  4. 学完做本讲习题：选择 / 判断题自动判分；推导 / 设计 / 编程题先自己写，再对照五要素解答并自评。
  5. 点「完成本讲」；进度、正确率、错题本自动进入 我的进度 面板。
  6. 每周看一次错题本，把已掌握的题目「标记掌握」移出。

四、学习数据与隐私

  • 默认全部数据保存在本机浏览器（localStorage，键 cslearn.progress.v1），不上传任何服务器。
  • 「我的进度」页可导出 JSON 备份、导出题目 / 章节 CSV 台账，也可导入恢复；换浏览器或清理缓存前请先导出。
  • 可选账号同步：本地服务运行时，在进度面板注册 / 登录即可上传 / 下载记录（跨设备）；密码为 scrypt 加盐哈希存储，同步内容仅学习数据。
  • 管理员在 #/admin 输入密钥，可查看 / 导出所有同步用户的汇总台账（用于教学管理统计）。

五、如何新增 / 修改内容（维护者必读）

5.1 新增或修改一讲

  1. 复制任意现有 content/courses/<课程>/<章>.json 作为模板。
  2. 按 docs/AUTHORING-GUIDE.md 填写：元信息、pro / kid 双讲解（节数一致、每章至少 1 张内联 SVG）、恰好 10 道习题（4/4/2）与五要素解答。
  3. 在对应 course.json 的单元章节列表登记新章（id、标题、课时、难度）。
  4. 校验：npm run validate；通过后 npm run build 刷新搜索索引与统计。

5.2 新增课程 / 交互动画

  • 新课程：在 content/courses/manifest.json 登记（id、名称、图标 SVG、学习路径），再建课程目录。
  • 新动画：读 docs/demo-spec.md，照 js/demos/sorting.js 的「帧序列 + 播放控制」模式实现 js/demos/<id>.js 与元数据 content/demos/<id>.json，并在 manifest 登记。
  • 换图（作者头像 / 网研所图标）：见 docs/asset-ledger.md，替换同名文件即可，无需改代码。

5.3 质量门槛（改完必须过）

命令检查什么
npm run validate每讲结构完整性：双讲解齐全与节数一致、10 题 4/4/2、五要素解答、字数基线、演示引用合法
npm run build重新生成搜索索引与首页统计（否则新章节搜不到）
npm run audit生成覆盖矩阵与审计报告（docs/coverage-matrix.csv、audit-report.json）
npm run smoke13 项端到端冒烟：页面、API、同步、判分记录、导出

六、部署

方案适合说明
静态托管（Netlify / Vercel / GitHub Pages）个人学习站、快速分享零成本上线；同步 / 管理员功能不可用，其余全功能。配置见 deploy/，步骤见 docs/deploy.md
Node 自托管（本地 / 局域网 / VPS）班级 / 家庭共用、需要跨设备同步HOST=0.0.0.0 node server/server.js；建议 pm2 守护 + Nginx/Caddy 做 HTTPS；数据在 server/data/，直接复制即备份

详细步骤、环境变量与安全注意事项见 docs/deploy.md。

七、已知限制与扩展建议

  • 内容深度对标「本科核心 + 研究生入门导读」，不替代教材与系统课程；后续可按 docs/OUTLINES.md 的同一格式扩充「计算机图形学」等课程。
  • 同步合并策略为「后写优先」，不支持多设备同时编辑的细粒度合并；频繁跨设备学习者建议每次学习结束手动同步一次。
  • 服务端按个人 / 小规模使用设计（无速率限制、无内置 TLS），公网部署请置于反向代理之后。
  • 值得做的下一步：错题本智能复习提醒（间隔重复）、课程内容包（把 content/ 打包分享）、PWA 离线缓存。
