# 设计决策留档（design-notes）

> 目的：让任何后续维护者（或审阅者）能看懂「为什么长这样」。依据设计能力规范的三轴路由留痕。

## 1. 风格锚点

- 采用 aesthetic-preset-library **preset 17「Takram · 日式思辨设计」**（用户指定）：柔和科技感——圆角、柔影、克制的配色，让严肃的计算机知识显得亲切；图表与演示是页面的主角。
- 提取的设计 DNA：概念优雅、柔影与圆角、图表即艺术、谦逊的精致、自然中性色（暖纸白 / 软灰 / 哑青绿）。

## 2. 色彩 Token（css/site.css :root）

| Token | 值 | 用途 |
|---|---|---|
| `--bg` | #FAF7F2 | 暖纸底色（非纯白，符合 craft 深浅端规范） |
| `--surface` | #FFFFFF | 卡片表面 |
| `--fg` / `--muted` | #26292E / #676B73 | 主文字（对 bg ≈13:1）/ 弱化文字（≈5.1:1） |
| `--accent` / `--accent-strong` | #46796B / #3A6659 | 主色青绿：白字在其上 5.0:1；文本级用加深档 6.1:1 |
| `--sand` / `--sand-ink` | #C9A96A / #7E622D | 砂金辅色：仅装饰；文本级用加深档 5.3:1 |
| `--link` | #3E6C8E | 链接蓝灰 5.3:1 |
| 语义色 | success/warn/danger | 低饱和绿/琥珀/砖红 + 对应 wash 底色 |

- 调色板四层结构（中性 70-90%、单一 accent 5-10%、语义 <5%、特效 <1%）按 craft 执行；每屏主色主用途不超过两处。
- 所有颜色仅经 `:root` 变量引用（P0：token 区之外无裸 hex）。

## 3. 字体决策（仲裁留痕）

- web-prototype 骨架默认 `--font-display` 绑定西文衬线。本站为**简体中文**内容，刻意改为 CJK 系统无衬线栈（PingFang / 鸿蒙 / MiSans / 思源黑 / 雅黑）+ 字重纪律（600）+ 负字距（-0.015~-0.025em）承担 display 角色。
- 理由：① Windows 无预装优质中文衬线（宋体大字号观感差且粗体为合成）；② 中文 Web 字体 3-8MB，违背离线可用与低带宽目标；③ cross-device 一致性优先。
- 依据设计规范仲裁规则：无品牌库时 craft 为兜底，但允许「有明确理由的偏离」——此文件即偏离声明。等宽与数字用系统 mono 栈（tabular-nums）。

## 4. 排版与布局

- 字阶 8 级（display 34-54 → xs 12），正文 16-17px，**中文阅读行高 1.9**；正文列宽 ≤ 65ch。
- 布局沿用 web-prototype 骨架的 token/组件体系（btn / card / pill / ds-table / topnav），并按应用形态扩展：章节页「侧目录 + 主文」双栏（≤1024px 收合为单栏）、练习与进度面板的卡片栅格。
- **偏离声明**：layouts.md 的 8 段式单页结构未逐字套用——交付物是多视图应用而非单页原型；已读取 example.html / template.html / checklist.md 并继承其 token 与组件。

## 5. 双讲解的视觉语言

- 专业版：默认纸面排版；宝宝巴士版：砂金 wash 容器 + 更口语的小节标题。
- 切换用 segmented 控件（`aria-pressed`），按节序映射保留滚动位置；版本选择持久化到本地进度存储。

## 6. 无障碍与降级（accessibility-baseline / animation-discipline / state-coverage）

- `:focus-visible` 2px 焦点环；跳转正文链接；触控目标 ≥40px；演示画布均带 `aria-label`；旁白即读屏文本。
- 动画统一「预计算帧序列 + 播放头」模式：系统开启「减弱动态效果」或低性能时自动放慢为分步模式，知识表达不丢失。
- 全部异步视图具备 加载骨架 / 空态 / 错误重试 三态；表单错误用 `aria-invalid` + 行内提示。

## 7. 反 AI 味自查（anti-ai-slop P0）

- 无紫蓝渐变、无 emoji 作图标（全站 SVG 线性图标）、无假数据（首页统计来自真实内容统计 stats.json）、无 lorem/占位文案、卡片不用「圆角+左彩条」组合。
- 首页 hero 的记忆点：一个「双讲解切换」的迷你示意面板，直接演示产品核心差异。
